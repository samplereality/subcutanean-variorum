Subcutanean Variorum

                
            

            

                
Overview

                
Every copy of Aaron Reed’s novel Subcutanean is different. Using a combinatorial narrative system, Reed generated thousands of unique versions by varying word choices, sentence structures, and entire passages.
 
                
The Subcutanean Variorum allows readers to compare multiple copies side-by-side to discover how the story shifts between versions.


                
Features

                
    
                    
  • 25 pre-loaded unique versions (seeds 60001-60025)
    • 
                    
  • Generate new versions and upload them for comparison
    • 
                    
  • Multiple view modes, including Side-by-side, Track Changes, Collation, and Source Code
    • 
                    
  • Analytical and visualization tools, including Variables, Heatmap, Word Differential, Story Pathways, Tapestry, Final Fight Breakdown, the Gonzo grid, and a CAVE immersive reader
    • 
                    
  • Bookmark your views, keyword search, word differential analysis, and more
    • 
                


                
How to Use

                
    
                    
  1. Select two or three versions using the dropdown menus
    2. 
                    
  2. Select a view or tool mode
    3. 
                    
  3. Navigate chapters using the chapter dropdown
    4. 
                    
  4. Search for text or analyze word differences
    5. 
                    
  5. Generate your own unique copy of the novel
    6. 
                    
  6. Upload additional EPUB or TXT copies of Subcutanean; Aaron Reed has made 10,000 variants readily available for download.
    7.

The Subcutanean Tapestry

                    
Each line traces a cluster of 10,000 unique copies—Seeds 50000-59999—across Subcutanean’s 22 chapters, from Prologue to Notes.

                    
Lines higher up contain rarer text; lines lower down share more text with other copies. Where threads bunch together, the copies are similar. Where they spread apart, the text diverges.

                    
You’re seeing one of three groups, based on which scene opens Chapter 1. Use the Club, Makeup, and Noodles buttons to reveal the others.

                    
Hover any thread for details. Click up to 3 threads to compare. Press i anytime for the full legend.

About Gonzo Mode

                
            

            

                
Overview

                
Gonzo Mode displays the same paragraph(s) from all 25 built-in versions of Subcutanean simultaneously in a 5×5 grid.


                
Each cell shows 10 paragraphs from a different seed, letting you see at a glance how the text varies across all versions.


                
Navigation

                
    
                    
  • Prev / Next — Move through paragraphs (10 at a time)
    • 
                    
  • Chapter dropdown — Jump to a different chapter
    • 
                    
  • Scroll any cell — All cells scroll together
    • 
                


                
Keyboard Shortcuts

                
    
                    
  • ← → ↑ ↓ — Previous/next paragraphs
    • 
                    
  • Page Up/Down — Jump 9 paragraphs
    • 
                    
  • Home / End — Go to chapter start/end
    • 
                    
  • ESC — Close Gonzo Mode
    • 
                


                
Cross-Highlight

                
Select text in any cell to see it highlighted across all 25 versions. Gold marks the source; cyan marks matches in other cells. Match counts appear in cell headers.


                
Empty Cells

                
If a version has fewer paragraphs than others, its cell will appear grayed out with "No content" displayed.
